A console your server
actually owns.

Route is an admin command framework for Roblox — typed arguments, wildcard permission nodes, and a console that's built server-side and cloned per player, so nothing a client sends is ever trusted on its own.

Built to be trusted, not just typed

Six things Route gets right by construction, not by convention.

Server-authoritative, always

Parse, resolve, validate, permission, guard, cooldown, execute, audit — every stage runs server-side, every time, independent of anything the client claims.

Typed arguments

24 built-in types — players, durations, colors, permission nodes — plus one-off enums and your own custom types, registered the same way as the built-ins.

Wildcard permission nodes

Dot-path strings like moderation.kick, checked with wildcards — moderation.* grants everything under it, * grants everything.

Nothing Rojo-authored

No StarterGui tree to find. The console is built via Instance.new() server-side and cloned into each player's PlayerGui on join.

Client-only commands

:runClient() for purely cosmetic, client-local conveniences — never touches the network, never reaches the server pipeline.

Audit log + Discord relay

Every command execution can be structured-logged and optionally relayed to a Discord webhook, filterable per event type.

Minimal to start, easy to extend

One require. One call. Commands are one small file each.

Write a command

local ServerScriptService = game:GetService("ServerScriptService")
local Route = require(ServerScriptService.Route.Route)
local Command, Types = Route.Command, Route.Types

return Command.new("givecoins")
	:permission("custom.givecoins")
	:arg(Types.players, "targets", "Who to pay")
	:arg(Types.integer, "amount", "How many coins")
	:run(function(ctx, args)
		-- ...
	end)

Boot the framework

local Route = require(ServerScriptService.Route.Route)

Route.Start({
	Commands = {
		Route.DefaultCommands,
		ServerScriptService.CustomRoute.Commands,
	},
	Permissions = {
		Owners = { 123456789 },
	},
})
